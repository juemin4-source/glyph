# Debug Report — HeadingParser createdAt bug

> Generated by: Investigate Combo (Investigate → Fix → Verify → Review)

---

## Symptom

`HeadingParser.parse()` creates `StoryNode` objects with empty `createdAt` and `updatedAt` fields (empty strings). The `StoryNode` interface defines these as required `string` fields.

## Root Cause

`parser/heading-parser.ts` lines 37-38:

```typescript
createdAt: '',
updatedAt: ''
```

The parser uses hardcoded empty strings instead of calling `new Date().toISOString()`. This means:
1. All nodes created via heading import have no creation timestamp
2. The timeline feature cannot sort imported nodes properly
3. Bookshelf sort order may be incorrect for imported projects

## Fix

Applied to `parser/heading-parser.ts`:

```typescript
// Before:
createdAt: '',
updatedAt: ''

// After:
const now = new Date().toISOString()
createdAt: now,
updatedAt: now
```
