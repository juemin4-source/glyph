# Gate C 用户体验返工报告（v0.4.4）

日期：2026-07-24  
基线：Gate C v0.4.3  
状态：候选源码完成，等待 Windows 完整构建与真实交互验收

## 一、返工原因

Gate C v0.4.3 在收紧文件安全主链时，把文件编辑器退化成了单一 Markdown 源码文本框，同时留下两个直接影响日常使用的问题：

1. 原有的可视化编辑、预览、格式工具、选区气泡菜单和斜杠命令消失；
2. 首页滚动条由居中的内容容器持有，视觉上紧贴右侧卡片内容；
3. Tauri 窗口关闭请求在存在冲突、缺失或保存异常时只阻止关闭，缺少可继续完成退出的恢复路径，且注册错误被静默吞掉。

本次只修复上述体验回归，不扩张 Gate C 的 AI 写入范围。

## 二、修改内容

### 2.1 恢复 Markdown 可视化编辑

重写 `components/FsDocumentView.tsx`，恢复三种工作模式：

- 可视化编辑；
- Markdown 源码；
- 只读预览。

恢复的写作能力：

- 常驻格式工具栏；
- 撤销、重做；
- 加粗、斜体；
- H1 / H2 / H3；
- 无序列表、有序列表；
- 引用、代码块、分割线；
- 文本选中后的气泡菜单；
- 输入 `/` 后出现结构命令；
- `Ctrl+S` 保存；
- `Ctrl+Shift+P` 切换预览；
- 当前光标和选区继续映射到 Markdown 偏移，供 Gate C 单文件 AI 行动使用。

新增 `utils/markdown-editor.ts`：

- Markdown → 可编辑 HTML；
- 可编辑 DOM → Markdown；
- 使用 DOM 树遍历序列化，不使用原先的正则 HTML 扁平转换；
- 支持小说写作常用的标题、段落、强调、删除线、行内代码、代码块、链接、图片、WikiLink、引用、列表和分割线；
- Markdown 文本仍是文件事实值；
- 源码模式始终保留，复杂或私有 Markdown 可直接编辑原文。

### 2.2 修正首页滚动条位置

修改 `App.tsx` 与 `styles/fs.css`：

- 新增全宽 `fs-welcome-scroll` 滚动层；
- 居中的首页内容只负责排版，不再持有滚动条；
- 滚动条回到窗口最右边，并留出稳定 gutter；
- 窄屏下保持合理内边距。

### 2.3 修复窗口关闭主链

重写 `App.tsx` 中的 `onCloseRequested` 处理：

- 所有关闭请求先阻止默认行为，再由统一关闭流程接管；
- 增加重入锁，避免一次点击触发并发保存和重复关闭；
- 正常状态先调用 `closeProject()`，完成保存与会话落盘后销毁窗口；
- 外部冲突时可先保存“本地冲突”副本再退出；
- 原文件缺失时可先保存恢复副本再退出；
- 普通保存失败时可选择保存恢复副本再退出；
- 用户取消时保持窗口打开；
- 注册失败和关闭失败不再静默吞掉，会写入日志并显示错误。

## 三、未改变的 Gate C 边界

- 一次 AI 任务仍只有一个正式目标文件；
- AI 生成与正式提交仍然分离；
- 新建不覆盖；
- 修改仍需磁盘版本校验；
- 修改前仍建立快照；
- 外部变化或编辑器变化仍阻止提交；
- 未增加删除、重命名、批量修改或项目外写入。

真实交互验收：

1. 打开普通 Markdown 小说文件；
2. 在可视化模式中输入、加粗、设标题、创建列表、引用与分割线；
3. 切换源码模式，确认 Markdown 正文可读且内容一致；
4. 切回可视化与预览，确认内容没有消失；
5. 使用选区发起 Gate C 改写，确认作用范围正确；
6. 首页产生纵向滚动时，确认滚动条位于窗口边缘；
7. 分别在干净、未保存、外部冲突、文件缺失状态点击窗口关闭键；
8. 确认取消可以留下，确认退出能够保存或生成恢复副本后关闭。
